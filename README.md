# Polski B1 — тренажёр грамматики

Откройте `index.html` двойным щелчком в современном браузере. Интернет для самого квиза не нужен; ссылки на оригинальные PDF открываются через интернет.

## Как заниматься

1. Выберите экзамен и тему в двух списках. Для каждого фильтра есть общий вариант «Все экзамены» или «Все темы». Если подходит несколько заданий, переходите между ними кнопками «Назад» и «Дальше».
2. Заполните поля в тексте или рядом с отдельными предложениями. Выбирайте варианты из списков или вводите ответы с польскими буквами.
3. В общей рамке выбранный вариант занимает одну копию. Если изменить или очистить ответ, эта копия снова станет доступна в других полях.
4. Нажмите «Проверить задание», чтобы увидеть итог и объяснения. Пустые поля отмечаются как пропущенные и учитываются в общем числе вопросов. «Пройти ещё раз» начинает это задание заново.

Переключение на другое задание сбрасывает его текущий проход. Накопленные ошибки сохраняются в памяти страницы до её обновления или закрытия.

## Самопрактика

Вверху страницы выберите «Самопрактика», чтобы открыть тему «Жильё»: слова и выражения, тексты с переводом, фотографию и задания на монолог и диалог. Отвечайте вслух и используйте список для самостоятельной проверки. Отметки не сохраняются после обновления страницы; автоматической оценки речи и подключения к ИИ нет. Вернуться к заданиям можно кнопкой «Грамматика».

## Обсудить ошибки с помощником

Нажмите «Скачать ошибки». Сохранится файл `polski-b1-oshibki.txt`: источник, номер задания, контекст, ваш ответ, образец и объяснение. Прикрепите его к сообщению помощнику для подробного разбора. Скачайте файл перед закрытием страницы.

В преобразованиях предложений возможны разные верные формулировки. Если автоматическая проверка не распознала ваш вариант, сравните его с образцом; кнопка «Мой вариант тоже верный» засчитает его по вашей оценке. Эта отметка попадёт в выгрузку.

Готовый банк: 20 опубликованных вариантов B1 за 2021–2024 годы, 145 грамматических заданий, 992 вопроса.

## Материалы

Исходные задания опубликованы Государственной комиссией по подтверждению знания польского языка как иностранного на certyfikatpolski.pl. Прямая ссылка есть у каждого задания. Примеры ответов и объяснения подготовлены для учебного тренажёра, они не являются официальным ключом или оценкой экзамена. Аудирование, сочинения и устная речь в грамматический квиз не входят; устная самопрактика доступна отдельно. В детских вариантах грамматика включена в раздел чтения; вопросы только на понимание текста исключены.

Интерфейс не отправляет ваши ответы на сервер и не подключён к внешнему чат-боту. Разбор в тренажёре — подготовленные объяснения. Для отдельного диалога скачайте ошибки и пришлите их в чат.

## Для изменения проекта

Данные находятся в `data/`, шаблон и логика — в `src/`.

Сборка одного автономного HTML-файла:

    python scripts/build.py --require-complete

Проверка сценариев:

    node scripts/verify.cjs

Готовый `index.html` содержит все данные и код; папки исходников для запуска не требуются.
